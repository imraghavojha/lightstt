# Model catalog

`Sources/LightTTSCore/Resources/models.json` is a JSON array. Entries have a stable filesystem-safe `id`, `name`, `engine`, optional qualitative five-point `speed` and `accuracy`, `languages`, and `size` in bytes. `whisper` entries have a direct immutable GGML `url` and SHA-256; `sherpa` entries contain a `version` identifying the ONNX layout and a list of relative `files`, each with an immutable URL, size, and SHA-256. FluidAudio `parakeet` entries select an SDK version; `canary` uses its int4 Core ML conversion. `apple` uses system-managed SpeechAnalyzer assets for the current locale, available on macOS 26 and later.

Whisper downloads are checksum-verified and can resume using URLSession resume data when the server supports it. Sherpa bundles download into a staging directory and verify each file before installation. FluidAudio downloads its model bundles using its own model hub. Apple assets are managed by macOS: removing the Apple row's installed state in LightTTS does not delete system assets. Parakeet Redux, Ultra, 110M, and Canary use CPU execution to avoid Neural Engine loading stalls observed on the test machine; v2/v3 use the SDK's default placement. Performance ratings are estimates, not benchmarks.

Custom whisper.cpp models can be imported as local GGML files, HTTPS URLs, or Hugging Face `owner/repository` (using `ggml-model.bin`). Sherpa-onnx, Parakeet, and Canary accept compatible local directories or Hugging Face repositories in the selected format. The repository importer pins its current commit, verifies file hashes, and expects the corresponding SDK conversion layout. A custom Whisper URL requires a SHA-256; local Whisper files are checked for the GGML header. Apple Speech models are system assets rather than user-importable files.

The sherpa-onnx package is pinned to 2.0.1 and is Apache-2.0 licensed; model and conversion licenses are separate. Model instances are created only on selection or transcription. MLX is not included: its additional runtime and dependency graph would increase distribution size, and no MLX model has been integrated and tested here.

For a model-path smoke test, run `lighttts-cli download MODEL_ID` followed by `lighttts-cli transcribe MODEL_ID sample.wav`. The CLI reads the same catalog and model store as the app. SpeechAnalyzer installation uses the current macOS locale and may require an Apple-managed asset download.

For non-Whisper multi-file models hosted outside Hugging Face, an HTTP(S) URL may point to a JSON manifest: an array of `{ "path": "relative/path", "url": "https://…", "size": 123, "sha256": "…" }` objects. Paths must match the selected engine format; every downloaded file is verified before installation.
