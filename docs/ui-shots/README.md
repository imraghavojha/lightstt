# UI captures

`ref-*` files are crops from the supplied local Superwhisper study. The study did not capture processing, completion, error, cancellation, or a light menu, so no reference for those states is included.

`popup-*` captures are from the built LightTTS application with `LIGHTTTS_UI_SHOT_STATE` selecting a deterministic state and `LIGHTTTS_UI_SHOT_APPEARANCE` selecting the appearance. The recording capture uses zero level to match the quiet reference; live audio drives the waveform in normal operation. Cancellation closes the panel when Always Show is off, so there is no visible popup to crop. The test mode does not start the microphone or shortcut monitor.

`menubar-dark.png` and `menubar-light.png` show the compact popover, opened with `LIGHTTTS_UI_SHOT_MENU=1`; `LIGHTTTS_TEST_AUDIO` suppresses permission onboarding for capture. The compact layout is a requested adaptation and has no direct Superwhisper reference. Microphone input selection was separately exercised with Core Audio device readback.

`popup-recording-wav-dark.png` is a real waveform frame from a 16 kHz mono WAV generated by `say` and `afconvert`, using `LIGHTTTS_TEST_AUDIO` and `LIGHTTTS_TEST_AUTOSTART=1`. Test audio is paced in real time, skips microphone and Accessibility permission requests, and does not paste or write history. `LIGHTTTS_TEST_AUTOSTOP_SECONDS` can stop the capture and exercise transcription.

The menubar-icon-dark.png file is a 2× screen crop of the actual LightTTS status item on the dark menu bar.
